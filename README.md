# Tobi Reader Extensions

Private extension ecosystem for Yomi Reader.

## Structure
- `index.json`: Master list of all available extensions.
- `icons/`: Extension icon images.
- `apks/`: Compiled extension APK files.

## How to add an extension
1. Build the extension APK.
2. Upload the APK to the `apks/` folder.
3. Upload the icon to the `icons/` folder.
4. Update `index.json` with the new extension details.
5. Commit and push to GitHub.
